# 第二阶段数据计划

目标是把原型升级为可导入、可校验、可审核、可追溯、可排行的本地 JSON 数据平台。

原则：
- 不做全网暴力爬虫。
- 不绕过登录、反爬、风控、付费墙或平台限制。
- 清修《明史》与清代官方叙事只作为 Q 级待核验对象。
- 网络文章、短视频、论坛、公众号、知乎等只作为 Lead。
- 所有 Evidence 必须追溯到 SourceRegistry。

推荐路线：
1. 阶段 A：人工录入 20 个高价值 Claim。
2. 阶段 B：每个 Claim 补 3-5 条 Evidence。
3. 阶段 C：建立 Source 白名单。
4. 阶段 D：导入 CHGIS / CBDB 等开放结构化数据。
5. 阶段 E：接入博物馆开放数据。
6. 阶段 F：针对热门争议补充原始文本和现代研究。
7. 阶段 G：再开放用户投稿或批量导入。
